Pricing

Credit-based pricing for the Meshy API.

The Meshy API uses a prepaid credit system. Purchase API credits from your subscription settings before making API requests. For volume pricing or custom contracts, contact our sales team.

Credit Calculator

Select an API and configure its options to estimate the credit cost of a single request. The pricing tables below provide the full breakdown.
